# Мой график — Android 0.5.0 (тестовая версия)

**Текущая версия:** удобное управление временными заменами дней, собственные типы дней в редакторе графика, выбор мелодии будильника и вибрации, выход на главную после отключения сигнала, импорт/экспорт графиков.

### Что нового в 0.5
- Быстрая замена типа дня **только на выбранную дату**, возврат к основному циклу и переход к следующему/предыдущему дню для серии замен.
- Можно создать свой тип прямо при добавлении дня в цикл и из редактора дня.
- На первой настройке объясняется назначение типов дней; текстовые поля запрашивают автозаглавную букву и автокоррекцию у установленной клавиатуры.
- После «Отключить» или «Отложить» на экране звонка открывается главная страница. Встроенные тестовые и рабочие сигналы остаются на системном Android AlarmManager.
- В разделе «Будильники» и настройках появился выбор системной мелодии и переключатель вибрации.
- В карточке выбранного дня явно указан источник и статус времени звонка — отсутствие сигнала больше не выглядит как пропавшее значение.
- Резервное копирование графиков в JSON и восстановление через системный файловый интерфейс.
- В CI: JUnit-тесты правил смен и будильников, затем сборка APK. Отдельный ручной UI-smoke на эмуляторах API 29/35. Подписанный релизный APK/AAB возможен при настройке владельцем приватных GitHub Actions Secrets.

**Не удаляйте предыдущую установку без экспорта графиков.** Debug APK из разных GitHub Actions могут быть подписаны разными сертификатами; для магазина нужен стабильный личный release-ключ. См. [docs/RELEASE.md](docs/RELEASE.md) и [docs/QA.md](docs/QA.md).

# История проекта — Android MVP 0.4.0

## Обновление 0.4.0: шаблоны смен, иконки и полноценный календарь

- Типы дней теперь имеют собственные иконки из девяти масштабируемых Android VectorDrawable-ресурсов (векторный XML, аналог SVG для Android), цвет, необязательное рабочее время и необязательный будильник по умолчанию.
- Каждый день цикла может наследовать рабочие часы и будильник типа, переопределить параметры только у себя или отключить. Если у типа будильник не указан, настройка наследуется от графика. Источник значения отображается прямо в редакторе.
- Выбор времени: прокрутка часов `00–23` и минут `00–59`, быстрые минуты `:00, :15, :30, :45`, без аналоговых часов.
- Главный календарь раскрывается на весь экран с переключением «Месяц / Неделя», крупными карточками дней и быстрым возвратом.
- Старые данные 0.3.x остаются совместимы; явно настроенные у старых смен часы интерпретируются как личное переопределение, а не затираются новым шаблоном.

### Системный планировщик и приложение «Часы»

Автоматические сменные будильники регистрируются через Android `AlarmManager.setAlarmClock()`: приложение управляет собственными идентификаторами, датами, отменой старых сигналов и восстановлением после перезагрузки. Существующий горизонт: текущий и следующий месяц с обновлением при переходе к следующему месяцу. Это надёжнее ограничения тремя сутками и не засоряет список будильников внешнего приложения «Часы».

Стандартный `AlarmClock.ACTION_SET_ALARM` умеет передавать время и дни недели, но не предоставляет универсальный способ узнать идентификатор созданной записи, запланировать её на произвольную дату и затем гарантированно отключить в «Часах». Поэтому автоматическое создание и удаление чужих будильников **не поддерживается**; доступен только явный ручной переход в системное приложение «Часы». Пользователь не должен видеть ложных обещаний о синхронизации.

### Проверка на телефоне

Проверить смены с ночной работой, редактирование шаблонного типа с распространением новых часов/будильника на все наследующие дни, индивидуальные переопределения, сохранение после рестарта, недельный календарь, доступность выбора времени с крупными пальцами, отмену будильников после выключения и паузы графика. Особенно проверить MIUI/HyperOS на заблокированном экране.

# История и возможности предыдущих версий

Нативный **Android**-календарь со сменами и **необязательными** точными будильниками. Интернета, рекламы, аккаунта и серверной части нет.


## Новый интерфейс 0.3

- **Главная:** крупная кнопка «Добавить график», карточка выбранного цикла, статистика типов дней, интерактивный календарь и карточка выбранной смены.
- **Графики:** отдельные карточки всех графиков; переключение только по нажатию «Выбрать», изменение цикла, даты начала, пауз, включения и удаления через меню.
- **Добавление графика:** шаг 1 — название и необязательный будильник; шаг 2 — порядок типов дней и настройки каждой смены; затем первый день выбирается касанием ячейки календаря.
- **Будильники:** отдельный экран со статусом системных разрешений, тестом через одну минуту и списком ближайших разрешённых сигналов.
- **Настройки:** управление типами дней и визуальной палитрой, объяснение режима паузы.
- **Иконка:** новый адаптивный значок с календарём и будильником для Android Launcher. Все данные из 0.2 сохранены в том же `ShiftStore`.
- **Навигация:** фиксированная нижняя панель «Главная · Графики · Будильники · Настройки».

В этой версии интерфейс реализован нативными Android View-компонентами, без дополнительной UI-библиотеки. Debug APK автоматически собирается GitHub Actions. Это **тестовая сборка** — точность будильников и интерфейс на конкретных моделях телефонов необходимо проверить отдельно.

## Функции

1. **Типы дней.** У типа задаются имя, цвет из визуальной палитры и признак «выходной». Можно создать «День», «Ночь», «Отсыпной», «Выходной», «Учёба» и любые другие. Изменение типа меняет его отображение во всех графиках. Нельзя удалить используемый тип до замены на другой.
2. **Несколько графиков.** У каждого свои название, цикл, дата начала, будильник по умолчанию, ручные правки и паузы. Новый график не заменяет выбранный: для перехода нужно явно нажать **«Выбрать»**. Только первый график выбирается автоматически. Удаление графика требует подтверждения; при удалении активного следующий график нужно выбрать вручную.
3. **Наложение цикла.** Сначала создать и заполнить цикл, затем нажать нужную ячейку календаря для назначения первого дня. Заполнены текущий и следующий месяцы. Длина цикла произвольна, смены могут быть ночными.
4. **Время работы — необязательно.** В каждой ячейке цикла можно включить или убрать часы начала/конца. В выбранной дате доступна ручная замена без изменения исходного цикла.
5. **Будильник — необязательно.** При создании графика он **по умолчанию выключен**. На уровне графика можно задать общее время и звонок накануне. У отдельного дня доступны три режима: **«По настройке графика»**, **«Отдельный будильник»** со своим временем и **«Без будильника»**. Для выходных типов будильники не назначаются. Любой день календаря можно изменить отдельно.
6. **Пауза — не удаление графика.** Пауза задаётся диапазоном дат или бессрочно. Во время паузы календарь **сохраняет типы и смены** (с пометкой `⏸`), а будильники не назначаются. По истечении паузы или после нажатия **«Вернуться к работе сегодня»** продолжается **тот же цикл, привязанный к прежней дате начала**. **Никакого сдвига фаз**: дни отпуска считаются в цикле, но не звонят. История пауз сохраняется; ошибочную паузу можно удалить.
7. **Включение/выключение.** Независимо от паузы у каждого графика есть переключатель **«График включён»**. Выключенный график не отображает смены и не планирует сигналы, но данные сохраняет. Повторное включение восстанавливает прежнюю привязку и сохранённые изменения.
8. **Системные будильники.** Android `AlarmManager.setAlarmClock()` + foreground service + звук/вибрация + экран и кнопки «Выключить»/«Отложить на 5 минут». При изменениях графика запланированные сигналы пересчитываются. Дополнительно проверяются ещё не доставленные старые сигналы, чтобы смена графика/пауза не запустили старый будильник. Есть тест на +1 минуту.
9. **Офлайн-хранение и миграция.** Профили, типы, паузы и исключения сохраняются локально. При обновлении из версии 0.1 старый одиночный цикл переносится в первый график; прежнее хранилище не стирается.

## Логика паузы: пример

Есть цикл из 4 дней: `День → Ночь → Отсыпной → Выходной`, дата начала — 1 ноября.

- 1 ноября: День, 2 ноября: Ночь, 3 ноября: Отсыпной, 4 ноября: Выходной.
- Пауза: **со 2 по 6 ноября включительно**. 2–6 ноября отображаются с `⏸`, будильники отменены.
- 7 ноября: **Отсыпной** (седьмой день соответствует третьему дню 4-дневного цикла), то есть цикл **не начинается заново** с «День».

Так можно использовать отпуск, болезнь, отгулы и временные перерывы, не теряя исходный ритм.

## Получение APK через GitHub Actions (без Android Studio)

1. Установите Git и GitHub CLI (`winget install --id GitHub.cli -e`), войдите: `gh auth login`.
2. Откройте PowerShell в **корне распакованного проекта**, где находятся `settings.gradle.kts` и папка `app`.
3. Выполните:

```powershell
git init -b main
git add .
git commit -m "Android MVP 0.2: shift types, multiple schedules and pauses"
gh repo create workshift-calendar --private --source . --remote origin --push
```

4. В созданном GitHub-репозитории откройте **Actions → Build Android APK**. После успешного запуска в **Artifacts → workshift-debug-apk** скачайте архив с `app-debug.apk`.
5. Извлеките APK и установите его на Android; при запросе разрешите установку из выбранного источника.

> Если репозиторий уже создан, используйте `git add .`, `git commit -m "MVP 0.2"`, `git push`, не выполняйте `gh repo create` повторно.

## Локальная сборка

Нужны JDK 17+; Gradle 8.13; Android SDK Platform 35 с Build Tools 35.0.0. Android Studio необязательна.

```powershell
java -version
gradle --version
gradle :app:assembleDebug
```

Путь: `app\build\outputs\apk\debug\app-debug.apk`.

Для использования wrapper (в проекте wrapper не включён): `gradle wrapper --gradle-version 8.13`, затем `./gradlew.bat :app:assembleDebug`.

## Проверка на телефоне

- Создайте типы «День» и «Ночь» с разными цветами через палитру.
- Создайте цикл из 4 дней и выберите дату начала в календаре. Проверьте текущий и следующий месяцы.
- Создайте **второй** график; убедитесь, что он не активируется автоматически; нажмите **«Выбрать»**.
- Выключите выбранный график и включите снова; привязка и данные должны сохраниться.
- Поставьте паузу на несколько дней; в календаре должны остаться пометки `⏸`, а будильники на эти дни должны исчезнуть. Снимите паузу досрочно и проверьте сохранение фазы цикла.
- Оставьте будильники полностью выключенными и проверьте календарь. Затем включите общий сигнал, отключите его для одной смены, а для другой задайте отдельное время.
- Разрешите точные будильники и уведомления **только если они нужны**. Проверьте «Тест: будильник через 1 минуту» на заблокированном экране, а также после перезагрузки.

## Важно

**Сборка и испытание на реальном телефоне в этом окружении не выполнялись.** Разные прошивки могут ограничивать запуск служб и воспроизведение сигналов; при принудительной остановке приложения Android может не доставлять события до следующего запуска. Полноэкранный показ требует разрешения в некоторых версиях Android. Debug APK предназначен для тестирования, а не публикации в магазине.
